# go-dev Skills

Reusable agent skills for building with [go-dev](https://github.com/eriicafes/go-dev).

## Install

```sh
npx skills add eriicafes/go-dev
```

## Available skills

| Skill | Description |
| --- | --- |
| [go-dev](go-dev/SKILL.md) | Development entrypoints, process reloading, child commands, skipping, readiness, hooks, and Vite refresh. |
